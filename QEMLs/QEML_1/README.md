# QEML-1: Git, Maven & Core Java Basics

## Overview

This microlearning course introduces foundational concepts and essential commands in Git, Maven, and Core Java, designed for junior engineers to build skills for managing code changes, configuring builds, and understanding core Java programming.

## Microlearning Objective

To enable junior engineers to manage code changes with Git, configure builds with Maven, and establish a solid foundation in Java programming fundamentals.

## Microlearning Goal

To confidently use Git, Maven, and core Java basics in collaborative software development projects.

## Course Structure

### 1. **Git Basics**
- Introduction to Git
- Git Commands: `git init`, `git add`, `git commit`, `git push`, `git pull`
- Branching and Merging
- Collaboration and Pull Requests

### 2. **Maven Basics**
- Introduction to Maven and its Build Lifecycle
- Dependency Management using `pom.xml`
- Plugins and Goals in Maven
- Building a Simple Java Project with Maven

### 3. **Core Java Basics**
- Variables and Data Types
- Control Structures: Loops, Conditionals
- Introduction to Object-Oriented Programming (OOP)
- Creating Classes and Objects
- Methods, Inheritance, Polymorphism, Encapsulation, Abstraction

## Tasks in QEML1

- **GIT**
- **Setting Up a Maven Project for Payroll Management**
- **Object and Class**
- **Implementing Inheritance**
- **Polymorphism**
- **Abstract Classes**
- **Encapsulating Sensitive Data**
- **Abstract Class & Interface**
- **Arrays Challenge**
- **Transitioning Arrays To Collections**
- **Collection Framework**
- **Sorting & Searching**
- **Annotations**
- **Generics**
- **Exception Handling**


## Learning Outcomes

Upon completing this microlearning course, you will:
- Understand how to manage code using Git and collaborate effectively with teammates.
- Configure and manage Maven projects with ease.
- Build a strong foundation in Java programming and object-oriented concepts.
